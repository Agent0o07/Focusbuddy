# Focusbuddy

**StudyStream Account Rotator** - Extension

A simple tool to help you switch between multiple StudyStream accounts during long focus sessions.

## Features
- Quick manual account switching from popup
- Stealth login with human-like typing simulation
- Browser fingerprint randomization (anti-detection)
- Automatic cookie & storage clearing
- Activity logs
- Fully customizable settings

## Browser Support
Works on **Chrome, Brave, Edge, Opera**, and other Chromium-based browsers.

## Installation

1. Download the latest version from Releases.
2. Unzip it
3. Go to `chrome://extensions/` (or `brave://extensions/` etc.)
4. Enable **Developer mode**
5. Click **"Load unpacked"** and select the `Focusbuddy` folder

## Usage
1. Open Settings and add your StudyStream accounts (email address & Password)
2. Go to any focus room
3. Use the popup to switch accounts

**Auto-rotation when timer ends is coming soon.**

## Privacy
All data (accounts, settings, logs) is stored **locally** in your browser.  
No tracking. No data collection. No external servers.
